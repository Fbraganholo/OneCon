# OneCon — Site Institucional

Primeira versão do site institucional da OneCon / Imperio Sul Consult.
Site OneCon publicado pelo GitHub Pages.

## Arquivos
- index.html
- style.css
- script.js
- assets/logo-onecon.jpg

## Publicação
O projeto pode ser publicado gratuitamente no GitHub Pages. Depois, podemos configurar domínio próprio, Google Search Console, Analytics, formulário de contato, conteúdo e os logotipos dos clientes.

## Observação
As áreas de clientes e conteúdos estão preparadas como estrutura inicial e podem ser preenchidas quando as informações forem fornecidas.
